# 心绪 · 情绪自我觉察（AIGC 应用创新大赛 · 赛题一）

面向杭电在校学生的一个小型情绪自我觉察网页：先做 5 题生活满意度（SWLS）自评，
再用 15 题基本心理需要（BNSG-S）看清「哪一部分在支撑你、哪一部分在消耗你」，
最后可以选择抽一张塔罗、或往本地树洞里写点东西。

**纯静态站点**：原生 HTML / CSS / JavaScript，无框架、无构建、无后端、无 Key，
所有数据只存在浏览器 `localStorage` 里。双击 `index.html` 就能跑。

> 结果仅供参考，**不能替代专业心理评估与诊断**。

## 本地运行

三种都行，推荐第一种：

```bash
# 在 生成式人工智能 文件夹里：任意静态服务器（热更新、file:// 限制更少）
npx serve .            # 或 python -m http.server 8080

# 2) 直接打开
start index.html       # 页面用普通 <script> 顺序加载，file:// 也能跑

# 3) 自测（不需要浏览器）
node tests/selftest.mjs
```

## 关键实现说明

**计分（`js/app.js` 的 `scoreBnsg`）** —— 这是全站唯一的「不能凭感觉写」的地方：

1. 每个因子先求条目分之和；带 `reverse: true` 的条目先做 1↔5 反向计分。
2. 因为「满足类」和「受阻类」方向相反，**不能直接拿原始分排序**。
   引擎按因子类型归一化成 0–100 的「问题指数」再比：
   - 满足类：`(满分 − 实得) / (满分 − 最低分) × 100`（分越低越值得留意）
   - 受阻类：`(实得 − 最低分) / (满分 − 最低分) × 100`（分越高越值得留意）
3. 取问题指数最高的一项；若第二名也 ≥ 45，就一起突出（最多 2 项）。
4. 若最高项 ≤ 30，判定为「比较均衡」，不贴「问题」标签。

**SWLS 分档**：总分 5–35，按 9 / 14 / 19 / 20 / 25 / 30 / 35 切成七档
（非常不满意 → 非常满意），每档配一段解释与一句引导语。

**随机**：只用了 `Math.random()`（按任务书要求，不引入密码学随机）。

**存储**：`localStorage` 前缀统一为 `xinxu.`，隐私模式下写入失败会静默退化成内存存储，不会白屏。

**牌面**：默认读取 `images/tarot/<两位序号>-<id>.jpg`（如 `00-fool.jpg`、`08-strength.jpg`），
正位直接显示、逆位整张旋转 180°。想换一套牌图时，替换同名文件即可；
把 `js/data/tarot.js` 的 `assetDir` 置空，就会回退到 `js/tarot-art.js` 的自绘矢量牌面。

**自测**：`node tests/selftest.mjs` 会把 `js/data/*` 和 `js/app.js` 放进 vm 沙箱执行，
直接调用线上同一份计分函数断言 —— 测的是真正运行的那份代码，不是另抄的公式。

## 需要人工补的一处

`js/data/scales.js` 里的 15 个 BNSG-S 条目目前是**结构正确、措辞待核对的占位初稿**
（文件顶部 `verified: false`，每条都标了 `draft: true`）。
定稿后：把条目文本换成文献原文 → 逐条确认 `factor` 与 `reverse` → 把 `verified` 改为 `true`
→ 删掉 `draft` 标记。此时结果页那句「本页条目仍在核对完善中」会自动消失。
