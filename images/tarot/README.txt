# 换成真实塔罗牌图（可选）

牌面默认是 `js/tarot-art.js` 自绘的金线矢量图，不依赖任何图片文件。
想把 22 张大阿卡纳换成真实图（例如 1909 年韦特公版画）：

1. 把 22 张图片放进本目录，命名 `<两位序号>-<id>.jpg`，序号从 `00` 到 `21`，
   `id` 用 `js/data/tarot.js` 里每张牌的 `id` 字段，例如：
   - `00-fool.jpg`（愚者）
   - `08-strength.jpg`（力量，8 号）
   - `11-justice.jpg`（正义，11 号）
   - `21-world.jpg`（世界）
2. 在 `js/data/tarot.js` 顶部的配置区把 `assetDir` 写成 `'images/tarot/'`。
3. 刷新页面即可；某张图缺失或加载失败时，那张牌会自动回退成矢量牌面，不会出空白。

逆位不需要单独准备图 —— 页面会把整张牌旋转 180°。
